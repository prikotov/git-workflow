## План проверок перед выкладкой

- Выполнить `make check` по правилам проекта; дождаться успешного результата
- Запускать сквозные тесты только по явному запросу пользователя; дождаться успеха запрошенных проверок
- До создания тега проверить, что PR из `hotfix/*` слит в `release/x.y.z` нового выпуска
- Проверить, что тег указывает на результат этого слияния, совпадающий по содержимому с одобренным коммитом `hotfix/*` и не содержащий невыпущенных изменений основной ветки
- Убедиться, что согласованный тег опубликован в `origin`
- Проверить необходимые изменения переменных окружения
- Проверить готовность миграций и безопасность порядка обновления кода и данных
